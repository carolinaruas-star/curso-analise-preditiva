### 🟢 Questão 6

* **Contextualização:** Implementação de duas regras de negócio com `datetime` e `timedelta`:
  1. Validação de idade em anos completos considerando se o aniversário já ocorreu no ano.
  2. Projeção de conclusão de curso com carga de 300h a 12h/semana (25 semanas).
* **Comando:** A alternativa que apresenta a implementação correta para a função de idade e a projeção da data de conclusão é:

#### Alternativa Correta:

* \[x\] **a)** 
```python
from datetime import datetime, timedelta

# 1. Função da Idade
def calcular_idade(data_nasc_texto):
    data_nasc = datetime.strptime(data_nasc_texto, "%d/%m/%Y")
    hoje = datetime.today()
    idade = hoje.year - data_nasc.year
    if (hoje.month, hoje.day) < (data_nasc.month, data_nasc.day):
        idade -= 1
    return idade

# 2. Projeção de Conclusão
data_matricula = datetime.strptime("17/08/2026", "%d/%m/%Y")
semanas_necessarias = 300 / 12  # 25 semanas
data_conclusao = data_matricula + timedelta(weeks=semanas_necessarias)
print(data_conclusao.strftime("%d/%m/%Y"))
```

> **Explicação:** A verificação de idade compara as tuplas `(mês, dia)` para saber se o aniversário do ano corrente já passou. Para o cálculo da data, 300 / 12 resulta em 25 semanas, repassadas diretamente ao parâmetro `weeks` do `timedelta`.

### 🟢 Questão 7

* **Contextualização:** Higienização de campos de telefone e CPF removendo caracteres não numéricos com expressões regulares (`\D`) e validação de tamanho de CPF (11 dígitos).
* **Comando:** A alternativa que apresenta o código correto em Python é:

#### Alternativa Correta:

* \[x\] **e)** 
```python
import re

telefones = ["(48) 99999-1234", "48 3222 5566", "+55 (48) 98888.7777"]
cpfs = ["123.456.789-00", "987 654 321 11"]

for tel in telefones:
    print(re.sub(r'\D', '', tel))

for cpf in cpfs:
    cpf_limpo = re.sub(r'\D', '', cpf)
    print(cpf_limpo)
    if len(cpf_limpo) == 11:
        print("Quantidade de dígitos está correta (11 dígitos).")
    else:
        print("Quantidade de dígitos incorreta.")
```

> **Explicação:** A expressão regular `\D` seleciona qualquer caractere que **não** seja um dígito numérico. O método `re.sub(r'\D', '', texto)` substitui esses caracteres por uma string vazia, deixando apenas os números.
