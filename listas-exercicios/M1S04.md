### 🟢 Questão 1
* **Contextualização:** Um desenvolvedor está trabalhando em um script no Google Colab para automatizar o sistema de concessão de descontos de um e-commerce. A regra de negócio define que um cliente terá direito ao "Desconto Especial" apenas se o valor total da sua compra for superior a R\$ 500,00 ou se ele possuir um cupom de fidelidade ativo. Além disso, para qualquer um desses casos, o sistema deve verificar se o produto não está na lista de "Liquidação", pois itens em liquidação não permitem descontos adicionais em nenhuma hipótese.
* **Comando:** Para validar corretamente a elegibilidade do cliente ao desconto conforme as regras apresentadas, a expressão lógica que define a condição de sucesso é:

#### Alternativa Correta:
- [x] **a)** `(valor_compra > 500 or cupom_fidelidade == True) and status_liquidacao == False`

> **Explicação:** O uso dos parênteses agrupa a disjunção (`or`), garantindo que a condição de valor ou cupom seja avaliada primeiro. O operador `and` em seguida conecta a obrigatoriedade de o produto não ser de liquidação (`status_liquidacao == False`), atuando como uma condição restritiva para ambos os casos anteriores.

### 🟢 Questão 2
* **Contextualização:** Um técnico de infraestrutura de TI está desenvolvendo um script em Python dentro do Google Colab para monitorar a saúde de um servidor de banco de dados. O script recebe dois valores de sensores em tempo real: a carga atual da CPU (armazenada como um número decimal) e o limite crítico de segurança definido pela equipe de redes (um número inteiro). O objetivo é que o script emita um alerta booleano (`True`) apenas quando a carga de processamento ultrapassar o limite de segurança.
* **Comando:** Para realizar essa comparação de forma tecnicamente correta, garantindo que o alerta seja disparado exatamente conforme a regra de negócio, o desenvolvedor deve utilizar a instrução:

#### Alternativa Correta:
- [x] **c)** `alerta = carga_cpu > limite_seguranca`

> **Explicação:** O operador relacional `>` (maior que) é o único que atende estritamente à regra de "ultrapassar o limite". Em Python, a comparação entre um tipo `float` (`carga_cpu`) e um `int` (`limite_seguranca`) é válida e resulta em um valor booleano (`True` ou `False`).

### 🟢 Questão 3
* **Contextualização:** Um desenvolvedor júnior recebeu a tarefa de criar uma célula de código no Google Colab para processar o fechamento de caixa de uma pequena loja. O sistema recebe o `valor_total_vendas` (`float`) e a `quantidade_vendas` (`int`). Para que o dia seja considerado "Alta Performance", a média de valor por venda deve ser superior a R\$ 150,00 e o número total de vendas deve ser de, no mínimo, 10 unidades.
* **Comando:** Para calcular a média e verificar se os dois critérios de performance foram satisfeitos simultaneamente, o desenvolvedor deve implementar a linha de código:

#### Alternativa Correta:
- [x] **c)** `meta_atingida = (valor_total_vendas / quantidade_vendas > 150) and (quantidade_vendas >= 10)`

> **Explicação:** Utiliza o operador aritmético de divisão (`/`) para calcular a média, o operador relacional `>` para verificar a meta de valor, e `>=` para incluir o limite mínimo de 10 unidades. O operador lógico `and` garante que ambos os critérios sejam atendidos simultaneamente.

### 🟢 Questão 4
* **Contextualização:** Um analista de suporte está desenvolvendo um pequeno utilitário no Google Colab para auxiliar o departamento de RH no cálculo do novo salário após um reajuste. Ao utilizar a função `input()` para receber o salário atual e a taxa de aumento, ele percebe que o código gera um erro de execução ao tentar realizar o cálculo matemático `salario * (1 + taxa/100)`.
* **Comando:** Para garantir que o cálculo aritmético seja executado corretamente e o programa processe os valores numéricos inseridos pelo usuário, o desenvolvedor deve:

#### Alternativa Correta:
- [x] **b)** Converter as entradas de texto para tipos numéricos como `float()` ou `int()` antes de realizar a operação.

> **Explicação:** Em Python, a função `input()` sempre retorna dados do tipo `string` (texto). Para realizar operações aritméticas, é obrigatório realizar o *casting* (conversão de tipo). Como salários e taxas costumam possuir casas decimais, a conversão para `float()` é a prática técnica mais adequada.

### 🟢 Questão 5
* **Contextualização:** Um desenvolvedor está criando um script de automação para um centro de distribuição que organiza pacotes em esteiras. O sistema precisa realizar uma ação de auditoria em todos os itens que possuem um número de identificação (`ID`) par.
* **Comando:** Para identificar corretamente os pacotes com identificação par e acionar a auditoria, a expressão lógica que deve ser aplicada é:

#### Alternativa Correta:
- [x] **c)** `id_pacote % 2 == 0`

> **Explicação:** O operador de módulo (`%`) retorna o resto da divisão inteira entre dois números. Na lógica computacional, um número é considerado par quando o resto da sua divisão por 2 é igual a zero (`== 0`).

### 🟢 Questão 6
* **Contextualização:** Um analista de segurança da informação está desenvolvendo um script em Python para validar o acesso a uma área restrita do servidor. A política estabelece que o acesso é permitido se o usuário for "Administrador" e se o horário for antes das 18h. Exceção: se o usuário possuir um "Token de Emergência" válido, o acesso deve ser concedido independentemente do cargo ou horário.
* **Comando:** Para implementar essa política de acesso garantindo que a exceção do token seja respeitada acima das outras regras, a expressão lógica correta é:

#### Alternativa Correta:
- [x] **a)** `acesso_permitido = (cargo == "Administrador" and hora < 18) or token_emergencia == True`

> **Explicação:** Os parênteses agrupam as condições padrão (`cargo` E `horário`). O operador `or` externo conecta o `token_emergencia`, garantindo que, se o token for `True`, toda a expressão se torne verdadeira independentemente das demais condições.

### 🟢 Questão 7
* **Contextualização:** Um técnico de TI precisa calcular a porcentagem de uso de memória RAM de um servidor. O script recebe o valor da `memoria_usada` e o valor da `memoria_total`.
* **Comando:** Para realizar o cálculo dessa métrica de desempenho garantindo que o resultado seja armazenado corretamente em uma variável numérica, o desenvolvedor deve aplicar a expressão:

#### Alternativa Correta:
- [x] **d)** `percentual_uso = (memoria_usada / memoria_total) * 100`

> **Explicação:** O operador de divisão (`/`) em Python 3 retorna um tipo `float`. Multiplicando o resultado por 100, obtém-se o valor percentual mantendo a precisão decimal necessária.

### 🟢 Questão 8
* **Contextualização:** Um desenvolvedor precisa validar se uma conta pode ser criada como "Conta Premium". Para isso, o usuário deve ter mais de 18 anos e possuir um convite válido (variável booleana). A idade capturada via `input()` precisa de conversão para evitar erros de tipo.
* **Comando:** Para corrigir o erro de execução e validar corretamente se o usuário cumpre os dois requisitos simultaneamente, a instrução técnica adequada é:

#### Alternativa Correta:
- [x] **c)** `pode_ser_premium = int(idade) > 18 and possui_convite == True`

> **Explicação:** A função `int(idade)` converte a string capturada do usuário para um número inteiro. O operador `and` garante que ambas as condições (idade superior a 18 anos E convite ativo) sejam satisfeitas juntas.

### 🟢 Questão 10
* **Contextualização:** Um servidor entra em "Modo de Manutenção" (`True`) caso a carga de processamento seja superior a 90% ou se estiver operando há mais de 720 horas ininterruptas. No entanto, essa ação **não** deve ocorrer se o servidor for classificado como "Missão Crítica".
* **Comando:** A expressão lógica que representa corretamente essa regra de negócio é:

#### Alternativa Correta:
- [x] **a)** `manutencao = (carga > 90 or horas_ligado > 720) and missao_critica == False`

> **Explicação:** Os parênteses garantem a avaliação primária da disjunção (`or`) entre carga e tempo de atividade. O resultado é então associado via `and` à validação de que o servidor não é de missão crítica (`missao_critica == False`).
