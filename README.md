## 📚 Introdução

Este repositório faz parte da minha jornada de aprendizagem em **Tecnologia, Dados e Inteligência Artificial**.

Foi criado com o **propósito de registrar e organizar os conhecimentos desenvolvidos ao longo da formação**, reunindo estudos, práticas, experimentos e projetos relacionados à análise de dados, Machine Learning e Inteligência Artificial.

Mais do que armazenar códigos e atividades, este espaço representa uma etapa do meu processo de aprendizagem, permitindo acompanhar minha evolução, documentar o que foi estudado e transformar os conhecimentos adquiridos em aplicações práticas.

## 📚 Sobre o curso

O curso Desenvolvimento de IA para Análise Preditiva aborda conceitos e práticas relacionados à aplicação de **Ciência de Dados, Machine Learning e Inteligência Artificial** na **construção de soluções preditivas**.

Ao longo da formação, os conteúdos são explorados de forma prática, passando por etapas como:

- preparação e tratamento de dados;
- análise exploratória;
- identificação de padrões;
- engenharia e seleção de atributos;
- construção de modelos de Machine Learning;
- avaliação de modelos;
- interpretação dos resultados;
- aplicação de técnicas de análise preditiva.

### 🌳 Wood Insight PY

Projeto desenvolvido como parte das atividades propostas pelo curso.

O projeto trabalha a **análise de dados de vendas do setor madeireiro**, utilizando Python para exploração dos dados, geração de métricas, segmentação de clientes e criação de visualizações.

O projeto reúne diferentes resultados e análises, incluindo:

- 📊 Estatísticas gerais;
- 📈 Métricas por mês;
- 👥 Segmentação de clientes;
- 📦 Análise da receita;
- 📅 Receita por mês;
- 📊 Receita por trimestre;
- 🏆 Top produtos;
- 🔎 Relação entre quantidade e receita.

#### 📊 Visualizações desenvolvidas

Entre os gráficos gerados pelo projeto estão:

- 📦 Box Plot — Receita;
- 🔥 Heatmap — Receita;
- 📋 Painel de Resumo;
- 📈 Quantidade × Receita;
- 📅 Receita por Mês;
- 📊 Receita por Trimestre;
- 🏆 Top Produtos.

Os resultados das análises e visualizações estão organizados na pasta `outputs/`.

📁 [`wood-insight-py/`](./wood-insight-py)
